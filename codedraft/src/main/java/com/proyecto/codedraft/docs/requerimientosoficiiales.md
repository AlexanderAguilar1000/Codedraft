# Plan técnico simplificado

Este plan considera que los datos se almacenarán en archivos JSON en lugar de usar una base de datos relacional.

## Orden de implementación

1. Crear la estructura base del proyecto y la configuración para manejar datos en JSON.
2. Implementar la funcionalidad para completar el perfil de usuario.
3. Implementar la funcionalidad para registrar cursos.
4. Implementar la funcionalidad para consultar la lista de cursos.
5. Implementar la funcionalidad para actualizar el estado de los cursos.
6. Implementar la funcionalidad para actualizar la prioridad de los cursos.
7. Implementar la funcionalidad para actualizar el progreso de los cursos.
8. Implementar la funcionalidad para eliminar cursos.
9. Implementar la funcionalidad para recomendar el siguiente curso a estudiar.
10. Implementar la funcionalidad para mostrar recomendaciones personalizadas según el perfil.
11. Implementar la funcionalidad para mostrar cursos sugeridos.
12. Implementar la funcionalidad del coach de aprendizaje.
13. Implementar la funcionalidad de mensajes motivadores del coach.
14. Implementar la funcionalidad de experiencia y puntos del usuario.

## Nota

Este plan se mantiene en un nivel general y no incluye detalles de pruebas unitarias, componentes adicionales ni elementos de interfaz como datepickers.
